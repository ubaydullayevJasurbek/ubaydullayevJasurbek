## 👨‍💻 About Me

I'm an **Android developer** who builds native apps in **Kotlin** and cross-platform apps in **Flutter**. I care about clean code structure, smooth UI and apps that keep working without a connection.

- 📱 Building native Android apps with **Kotlin**, **XML Views + ViewBinding** and **Material Design**
- 🏗️ Structuring projects with **MVVM** and **Clean Architecture** (`data` / `domain` / `presentation`)
- 💾 Offline-first storage with **Room** (Android) and **Isar** (Flutter)
- 🌐 Working with REST APIs through **Retrofit + OkHttp** and **Dio**
- 🔐 Authentication with **Firebase Auth** and **Google Sign-In** via Credential Manager
- 🌱 Currently growing **Finara**, my personal finance app, one feature branch at a time
